Getting started.+
  1. Extract all ZIP contents, then open SoftFex AI.exe.
  2. Configure your Anthropic key through the masked local prompt. Choose your project and enable AI review.
  3. Use Review Now, or connect the Codex CLI for automatic reviews.

Automatic Codex reviews require Node.js 24+, Python 3.11+ and an authenticated Codex CLI. Connection instructions ↗

Deepgram voice is optional; system voice is available. This unsigned Windows beta may show a security warning. Reviews have limited coverage and can miss issues. macOS is not available in this release.
